# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2025-12-06

### Added
- Initial release of zzChatTTS
- TTSEngine class for text-to-speech conversion
- Support for single and batch text processing
- Command-line interface (CLI) for easy usage
- Customizable voice parameters (temperature, top_p, top_k)
- GPU acceleration support via CUDA
- Comprehensive documentation and examples
- Unit tests for core functionality
- Example scripts demonstrating usage
- MIT License

### Features
- High-quality text-to-speech using ChatTTS model
- Easy-to-use Python API
- Batch processing capabilities
- File-based text input support
- Configurable sampling parameters
- Audio file export in WAV format
